# AGENTS.md（NAGARE が入れたもの）

このリポジトリでは、コードを書くのは Claude Code（NAGARE の `nagare-*` エージェント）で、Codex は独立したレビュー役です（NAGARE の D27・D29）。Codex はファイルを変更しません。

## Code Review Rules

### 何を見るか
- 仕様の要求（`nagare/02_spec` の要求 ID）と、実装が食い違っていないか。食い違いには要求 ID を書く
- 計画の作業包（`nagare/03_plan`）の「作るもの」「含まないもの」を外れていないか
- 規約の違反のうち、Lint が拾えないもの。規約を指すときはルール ID（例：R-CLK-04）を書く
- 半導体の RTL では、リセットの抜け、クロックをまたぐ所の扱い、意図しないラッチ、仕様の端（満杯・空・最大値）の扱い

### 何を指摘しないか
- Lint や書き方の検査がすでに拾うもの
- 個人の好み、根拠のない推測、今回の変更で触っていない既存の問題
- テストの合否（合否は⑤の検証で、EDA の結果から決める）

### 書き方
- 指摘ごとに、場所（ファイルと行）、重さ（P0〜P3）、根拠を1文で書く
- 実行していない検査の結果を、実行したように書かない
