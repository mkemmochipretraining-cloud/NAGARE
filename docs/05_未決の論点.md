## 論点 h（D27 で決定）：Claude Code が書いたコードを、別の AI にレビューさせるか（2026-11-24 調べ）
- ねらい：同じモデルは同じところを見落とすので、学び方の違う AI にレビューさせる（D13 の考え方を、モデルの層まで広げる）
- 案 A：ChatGPT（Codex）。費用のメモ（2026-11 時点の OpenAI の料金ページ）：Go 月8ドル／Plus 月20ドル／Pro 月100ドル（Codex の使用量が Plus の5倍）・月200ドル（20倍）。API キーで使う場合は使った分だけの料金。どのプランにも使用量の上限がある。private のコードが OpenAI に渡る
- 案 B：大きなオープンウェイト（DeepSeek V4 系など）を API で使う。手元では動かせない：V4-Flash は全体で 284B（1トークンあたり 13B が動く）、FP8 版で約 294GB あり H100 を8枚使う。V4-Pro は 1.6T で、重みが約 865GB。24GB の GPU ではどちらも動かせない。コードは API の提供元に渡る
- 案 C：小さなオープンウェイトを手元で動かす。RTX 3060 12GB の実例：Qwen3.6-27B は q3_K_M なら GPU に収まる（文脈 4K〜8K、毎秒6〜9トークン）。q4_K_M で一部を CPU のメモリに逃がすほうが、コードには向くとの報告。レビューは手元の小さいモデルが得意な使い道とする解説がある。見つけた実例はソフトウェアのコードで、RTL のレビューの実例は見つかっていない
- 案 D：AI のレビューを置かず、EDA の検査と人に任せる
- 物差しの案：わざとバグを入れた RTL をレビューさせ、見つけた数で比べる
- 出典：developers.openai.com/codex/pricing、thundercompute.com/blog/deploy-deepseek-v4-locally、specpicks.com/reviews/qwen-3-6-27b-rtx-3060-12gb-2026、llmconfigurator.com/en/guides/coding-agents/local-code-review-agent
