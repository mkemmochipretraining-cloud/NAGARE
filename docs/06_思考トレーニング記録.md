# 思考トレーニング記録（2026-11-14）

← [README](../README.md)

7つの思考の型（①問いの再定義 ②分解 ③発散 ④反証 ⑤確信度 ⑥結論先出し ⑦見直し）について、この検討の中での状態をまとめる。

## 到達点

| 型 | この日の状態 | 次の課題 |
|---|---|---|
| ①問いの再定義 | 「そもそも誰が書くのか」「そもそもまだ回していない」など、前提に戻る問いが何度も出た（4） | 問いの前に「そもそも〇〇のため」と自分の答えを1行添える |
| ②分解 | 「作る道」と「確かめ方を決める道」の分離、時間帯を作業の重さで分ける、など名前のある分け方ができた（4） | 分けた軸に漏れ・重なりがないかを確かめる |
| ③発散 | 案 E（併存）を自分で出した。他業界にお手本を探す依頼を自分から出した（5） | 自分の案を出してから相手に聞く |
| ④反証 | 「30％以上外れたら」「1件でもだめ」で、崩れる条件を物差し付きで書けた回が1回（3） | 自分の案どうしの矛盾、仕組みの組み合わせの順番、安全装置そのものが抜け穴にならないか、まで疑う |
| ⑤確信度 | 「はっきりしない」と、確信が低いことを自分で言えた（2〜3） | ％を付ける。「〜気がする」「〜のでは？」を％に置き換える |
| ⑥結論先出し | 3回続けて合格水準。**5と判定** | このまま続ける |
| ⑦見直し | 誤字や途中で切れた文が残ることが多かった（1〜2） | 送る前に読み返す。聞かれた問いの数を数えてから返す |

## よく出た指摘
- 「〜ですね」「〜気がする」「〜のでは？」「大きく」など、言い切らない言葉・数字のない言葉
- 聞かれた問いの一部に答えずに返す（問いの数を数える）
- 仕組みを2つ組み合わせたときの順番の落とし穴（副本の上書きと定期の比較）
- 自分の出した考えどうしの矛盾（「両方を見せる」と「自動で連動」）
